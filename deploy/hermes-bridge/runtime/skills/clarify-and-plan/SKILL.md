# Clarify and plan

## Procedure

1. Read the request and available project context. Ask only questions whose answers materially affect the result.
2. Use simple language and short choices. Group at most three questions; avoid technical setup questions the application can resolve.
3. For a clear request, make reasonable assumptions and state them briefly. For a missing required decision, ask and make no dependent file changes.
4. For larger work, outline a short sequence with an observable result for each step. Execute authorized work in manageable steps using tools.
5. Track progress and stop when the requested outcome is achieved, a required answer is missing, or the application limit is reached.

## Completion

Explain what is prepared, what was checked, and the next useful action. Never report unperformed work as complete.

# Frontend design

## Procedure

1. Identify the audience, page purpose, existing stack, and content. If the desired style is missing, choose and explain one suitable direction or ask one short question when the choice matters.
2. Read the HTML/components, CSS/tokens, and relevant scripts before editing. Keep existing content and behavior unless asked to change them.
3. Establish a coherent visual direction: a restrained palette, readable type scale, consistent spacing, clear hierarchy, and a deliberate page composition. Avoid generic repeated cards, arbitrary gradients, and decorative clutter.
4. Implement a complete responsive layout with useful mobile behavior. Preserve accessible headings, labels, visible keyboard focus, readable contrast, and usable controls.
5. Check document structure, resource links, and available syntax/build checks. If you cannot inspect a rendered page, say so; never claim a visual check happened.

## Completion

Describe concrete improvements and prepared file changes. Do not substitute a description for the actual implementation.

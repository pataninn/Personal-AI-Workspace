# Task 6.2 source map

## Backend implementation

- The skill module consists of `backend/src/modules/skills/index.ts`; `controllers/skill-router.ts` and `controllers/skill-router.spec.ts`; `domain/skill-types.ts`, `domain/skill-invocation-types.ts`, `domain/skill-validation.ts`, and `domain/skill-validation.spec.ts`; `repositories/skill-repository.ts` and `repositories/skill-invocation-repository.ts`; and `use-cases/create-skill.ts`, `delete-skill.ts`, `get-skill.ts`, `list-skills.ts`, `update-skill.ts`, `invoke-skill.ts`, `skill-use-cases.spec.ts`, and `invoke-skill.spec.ts`.
- `Personal-AI-Workspace/backend/src/infrastructure/database/migrations/1710000035000-create-skills.ts` adds skills, immutable revisions, invocation metadata, the trusted Home-turn binding, and the sanitized showcase skill snapshot. `backend/src/infrastructure/database/data-source.ts` registers migration 0035 after delivered migration 0034.
- `backend/src/infrastructure/database/repositories/typeorm-skill-repository.ts` and its `.spec.ts`, plus `typeorm-skill-invocation-repository.ts` and its `.spec.ts`, implement and verify versioning, owner-scoped idempotency, immutable history, replay, turn binding lookup, and current-source checks.
- `backend/src/infrastructure/database/storage-content-accounting.ts`, `storage-content-accounting.spec.ts`, and `storage-content-projections.ts` account revision title, instructions, and declared tools through the existing quota path. `backend/src/infrastructure/database/repositories/typeorm-project-removal-repository.ts` selects skill revision identities for normal workspace deletion and quota release.
- `backend/src/modules/home-assistant/domain/home-conversation-types.ts`, `domain/home-planning-context.ts`, `repositories/home-conversation-repository.ts`, `use-cases/submit-home-turn.ts`, `submit-home-turn.spec.ts`, `get-home-turn.ts`, `home-planning-tool-request-handler.ts`, and `home-planning-tool-request-handler.spec.ts` carry the trusted invocation marker and the ID/revision-only transcript snapshot through the existing turn path. Infrastructure persistence is in `backend/src/infrastructure/database/repositories/typeorm-home-conversation-repository.ts` and `home-conversation-persistence-mappers.ts`. Its `.spec.ts` updates the insert parameter expectation for the nullable marker. Ordinary null-marker turns retain their behavior; surviving bound turns with missing or mismatched invocation sources fail closed.
- Showcase allowlist/projection sources are `backend/src/modules/showcases/domain/showcase-types.ts`, `controllers/showcase-router.ts`, `use-cases/showcase-use-cases.ts`, `use-cases/showcase-use-cases.spec.ts`, `backend/src/infrastructure/database/repositories/typeorm-showcase-repository.ts`, and its `.spec.ts`. `typeorm-demo-showcase-copy-manager.ts` copies only selected pinned skills into generated private IDs and version-1 revisions, with the existing content accounting scan.
- `backend/src/app.ts`, `backend/src/composition-root.ts`, `backend/src/infrastructure/database/data-source.ts`, and `backend/openapi.json` mount, wire, migrate, and describe the authenticated skill API and showcase skill fields.
